# Diplo Translator Omni Support

This is the public support repository for **Diplo Translator Omni for Umbraco**.
It contains support resources and public issue tracking only. The product source code is maintained in a separate private repository and is not published here.

## Get help

- [Ask a question](https://github.com/DanDiplo/Diplo.Translator.Omni-Support/discussions/categories/q-a) in Discussions for setup, configuration, and usage help.
- [Suggest an idea](https://github.com/DanDiplo/Diplo.Translator.Omni-Support/discussions/categories/ideas) for feature proposals and broader product feedback.
- [Report a reproducible bug](https://github.com/DanDiplo/Diplo.Translator.Omni-Support/issues/new/choose) using the structured issue form.
- For a possible security vulnerability, follow the private process in [SECURITY.md](SECURITY.md). Do not disclose vulnerability details in a public issue or discussion.

Please search existing issues and discussions before opening a new report.

## Public information warning

Everything posted in Issues and Discussions is public. Before submitting, remove:

- API keys, access tokens, passwords, and connection strings;
- personal data and customer content;
- confidential prompts, translations, logs, and screenshots;
- private URLs, internal hostnames, and commercially sensitive information.

Sanitised excerpts that reproduce the problem are welcome. If sensitive material is essential to investigating a security issue, use private vulnerability reporting instead.

## Scope

Issues are intended for actionable, reproducible defects and documentation problems. Questions, troubleshooting conversations, and early feature ideas belong in Discussions.

Submitting an issue does not grant access to the private source repository, create a service-level agreement, or guarantee that a requested change will be implemented.

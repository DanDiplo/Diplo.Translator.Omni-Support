# Security Policy

## Reporting a vulnerability

Do not report suspected security vulnerabilities through public Issues or Discussions.

Use GitHub's **Report a vulnerability** option in the Security area of this repository. Reports submitted there are private and visible only to the reporter and repository maintainers.

Include, where possible:

- the affected Diplo Translator Omni and Umbraco versions;
- the impact and conditions required to reproduce the issue;
- minimal, sanitised reproduction steps;
- any suggested mitigation;
- whether the vulnerability is already public or has been shared elsewhere.

Do not include API keys, credentials, customer content, or personal data. We will acknowledge the report and coordinate next steps privately. Please allow time for investigation and remediation before public disclosure.

## Supported versions

Security fixes are evaluated for the latest available Diplo Translator Omni release or pre-release. Older versions may require upgrading before a fix can be applied.
